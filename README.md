# Fix addon [m1pro](https://addons.mozilla.org/ru/firefox/addon/m1pro/) for [m1.gg/monopoly-one.com](https://monopoly-one.com/)

**How to Install** 
1. Download the ZIP file and extract it to any folder of your choice.
2. Open Firefox and enter [about:debugging] in the address bar.
3. Go to the “This Firefox” section.
4. Click “Load Temporary Add-on…”.
5. Select [manifest.json] from the extracted folder.
6. Open Monopoly One and refresh the page.

**Как установить**
1. Скачайте ZIP-файл и распакуйте его в любую папку по вашему выбору.
2. Откройте Firefox и введите [about:debugging] в адресную строку.
3. Перейдите в раздел «Этот Firefox».
4. Нажмите «Загрузить временное дополнение…».
5. Выберите файл [manifest.json] из распакованной папки.
6. Откройте Monopoly One и обновите страницу.
